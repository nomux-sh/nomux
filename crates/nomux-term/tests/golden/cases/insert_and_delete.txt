# Insert and delete of characters (ICH, DCH, ECH) at the end of the row.

case ICH of more cells than the row has empties the rest of the row
follows ECMA-48 8.3.64 ICH; xterm ctlseqs "CSI Ps @"
input abcdef\e[1;3H\e[99@
screen
|ab                  |
|                    |
|                    |
|                    |
|                    |
cursor 0,2

case DCH of more cells than the row has empties the rest of the row
follows ECMA-48 8.3.26 DCH; xterm ctlseqs "CSI Ps P"
input abcdef\e[1;3H\e[99P
gap A count larger than the cells from the cursor to the end of the row also erases the cells before the cursor: the library erases the last `count` cells of the row
