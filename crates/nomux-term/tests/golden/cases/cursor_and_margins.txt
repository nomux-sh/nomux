# Cursor motion against the margins of the scroll region, and the saved cursor.

case CUP without parameters goes to the first cell
follows ECMA-48 8.3.21 CUP, default 1;1; vttest "cursor movements"
input \e[3;5HX\e[HY
screen
|Y                   |
|                    |
|    X               |
|                    |
|                    |
cursor 0,1

case CUU stops at the top margin inside the scroll region
follows DEC STD 070 CUU; xterm ctlseqs "CSI Ps A"
input \e[2;4r\e[3;1H\e[9AX
gap CUU ignores the top margin and stops at the first row of the screen

case HPA, HPR and VPR move in one coordinate
follows ECMA-48 8.3.57 HPA, 8.3.59 HPR, 8.3.160 VPR; xterm ctlseqs "CSI Pm `", "CSI Pm a", "CSI Pm e"
input \e[5`A\e[2aB\e[2eC
