# Queries: the program asks the terminal, and the terminal answers on the input side.
# Each case shows that the query puts nothing on the screen, and the answer of nomux-term.

case primary device attributes
follows xterm ctlseqs "CSI Ps c"; nomux is a VT220 (62) with ANSI colors (22)
input \e[c
reply \e[?62;22c
