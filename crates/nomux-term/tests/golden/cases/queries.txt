# Queries: the program asks the terminal, and the terminal answers on the input side.
# nomux-term answers no query. Each case shows that the query puts nothing on the screen.

case primary device attributes
follows xterm ctlseqs "CSI Ps c"
input \e[c
gap No answer. xterm answers \e[?Pl;Pa...c: its terminal level and its attributes
screen
